# 旅游路线推荐系统

> 一个基于 Flask + SQLite + 高德地图 API 的全栈旅游路线推荐与智能定制平台，支持 15 座热门城市的路线浏览、个性化行程定制、足迹打卡与导出分享。

---

##  主要功能

### 路线浏览
- 首页展示热门城市及推荐路线，支持按城市筛选
- 路线详情页：左侧地图（高德瓦片 + Leaflet）实时展示路线轨迹，右侧完整行程时间线
- 景点信息卡片：展示名称、分类、门票价格（真实数据）、坐标定位

### 智能定制行程
- **4 步定制问卷**：出行偏好 → 目的城市 → 天数 / 预算 / 交通方式 → 确认
- **路线生成算法**：
  - 基于偏好加权排序景点
  - 方向性贪心排序（南北 / 东西向规划，减少折返）
  - 每日景点分配（含游玩时长限制、去重）
  - 自动选择住宿（靠近当日景点）与餐饮
- **生成 3 套差异化方案**（偏好方向偏移实现多样性）
- **路线可视化编辑**：Leaflet 地图 + 可编辑行程时间线，支持增删替换景点
- **路线优化**：2-opt 算法优化景点访问顺序（TSP）

### 用户系统
- 注册 / 登录 / 登出（Flask session，Werkzeug 密码哈希）
- 收藏路线、浏览历史自动记录
- **足迹打卡**：在路线详情页对单个景点标记"去过"，足迹地图用坐标标注所有打卡点
- **个人中心**：三标签页（收藏 / 足迹地图 / 浏览历史）+ 我的定制路线

### 行程导出
- 将路线或定制行程导出为精美图片（Pillow 生成）
- 支持 3 种导出样式：现代卡片 / 地铁线路图 / 信息图表
- 定制结果页与个人中心页均支持一键导出

###  数据规模
| 类型 | 数量 |
|------|------|
| 覆盖城市 | 15 座（北京、上海、杭州、成都、西安、厦门、丽江、三亚、桂林、青岛、苏州、南京、重庆、广州、深圳） |
| 景点 | 750 条（含真实门票价格：241 收费 / 509 免费） |
| 酒店 | 750 条 |
| 餐厅 | 750 条 |
| 预置路线 | 60 条（每城 4 条） |

## 技术栈

| 层级 | 技术 |
|------|------|
| **后端框架** | Flask 2.3 + Flask-SQLAlchemy |
| **数据库** | SQLite（SQLAlchemy ORM） |
| **模板引擎** | Jinja2 |
| **前端地图** | Leaflet.js + 高德地图瓦片 / POI API |
| **图片生成** | Pillow (PIL) |
| **鉴权** | Werkzeug security（密码哈希）+ Flask session |
| **数据采集** | 高德地图 REST API（`requests`） |
| **环境配置** | python-dotenv |
| **开发工具** | pytest / black / flake8 |

## 项目结构

```
travel_recommending/
├── app.py                    # Flask 主应用，所有路由与 API 端点
├── config.py                 # 配置（数据库、高德 API Key、城市列表等）
├── requirements.txt          # Python 依赖
├── export_itinerary.py       # 行程图片生成核心逻辑
├── export_styles.py          # 3 种导出样式定义
│
├── models/                   # 数据库模型（SQLAlchemy）
│   ├── attraction.py         # 景点（含分类、票价、游玩时长、坐标）
│   ├── hotel.py              # 酒店（含价格、坐标）
│   ├── restaurant.py         # 餐厅
│   ├── route.py              # 预置路线
│   ├── custom_route.py       # 用户定制路线
│   ├── user.py               # 用户账号
│   └── user_data.py          # 收藏 / 足迹 / 浏览历史
│
├── services/                 # 业务逻辑层
│   ├── route_generator.py    # 智能路线生成算法（偏好加权 + 方向性排序 + 每日分配）
│   ├── route_optimizer.py    # 2-opt TSP 路线优化
│   ├── amap_service.py       # 高德 API 封装
│   └── data_generator.py     # 数据初始化辅助
│
├── templates/                # Jinja2 HTML 模板
│   ├── index.html            # 首页（城市 / 路线浏览）
│   ├── route_detail.html     # 路线详情（地图 + 时间线）
│   ├── customize.html        # 定制问卷（4 步流程）
│   ├── customize_results.html# 定制结果（地图编辑 + 导出 + 保存）
│   ├── profile.html          # 个人中心（收藏 / 足迹 / 定制路线）
│   └── 404.html / 500.html   # 错误页
│
├── static/                   # 静态资源（CSS / JS / 图片）
│
├── scripts/                  # 数据库工具脚本
│   ├── init_database.py      # 初始化数据库表结构
│   ├── scrape_amap_poi.py    # 高德 POI 批量爬取（景点 / 酒店 / 餐厅）
│   ├── enrich_data.py        # 数据补全（图片、标签等）
│   ├── update_ticket_prices.py # 更新真实门票价格（15 城精确映射）
│   ├── update_durations.py   # 按关键词更新景点游玩时长
│   └── migrate_database.py   # 数据库字段迁移
│
└── data/
    ├── travel.db             # SQLite 主数据库
    └── cities.json           # 城市元数据（中文名、坐标中心等）
```
